# Bright Body

A 3D action adventure game. Art and animation are made in **Blender**, and the game runs in **Godot 4**.

The current milestone is a **playable combat prototype**: a greybox arena, a third person hero with melee and
ranged combat, and two enemy types.

## Getting started

1. Install [Godot 4.4+](https://godotengine.org/download) (the standard build, no .NET needed).
2. Install [Blender 4.2+](https://www.blender.org/download/) if you want to edit or create art.
3. In Godot, choose **Import**, pick `game/project.godot`, then press **F5** to play.

## Controls

| Action | Keyboard / mouse | Gamepad |
| --- | --- | --- |
| Move | WASD | Left stick |
| Camera | Mouse | Right stick |
| Sprint | Shift | L3 |
| Jump | Space | A / Cross |
| Dodge roll | Ctrl or C | B / Circle |
| Melee attack (3 hit combo) | Left click | RB / R1 or RT / R2 |
| Aim | Hold right click | Hold LT / L2 |
| Shoot | Left click while aiming | RT / R2 while aiming |
| Lock on / release | Tab or middle click | R3 |
| Restart | R | Start |
| Free the mouse | Esc | |

## What the prototype has

- **Player** (`game/scripts/player/player.gd`): camera relative movement, sprint, jump, stamina, dodge roll with
  invulnerability frames, a buffered three hit melee combo, over the shoulder aiming with projectiles, and
  lock on targeting. All tuning values are exported, so they can be tweaked in the Godot inspector.
- **Enemies** (`game/scripts/enemies/enemy.gd`): *Brutes* (red) close in and swing after a glowing windup.
  *Casters* (purple) keep their distance and throw slow, dodgeable projectiles. Hitting an enemy during its
  windup staggers it and cancels the attack.
- **Level** (`game/scenes/levels/main.tscn`): a greybox arena built from CSG shapes, with pillars, cover,
  a ramp to a raised platform and jump steps.
- **HUD**: health, stamina, enemy counter, crosshair and a lock on marker.
- **Hero model**: a blocky placeholder generated by a Blender script, rigged and animated
  (Idle, Run, Jump, Attack1 to 3, Shoot, Dodge, Hurt, Death).

## Repository layout

```
blender/
  scripts/        Python scripts run by Blender (export, placeholder generators)
  source/         .blend source files
game/             The Godot project (open game/project.godot)
  assets/models/  Exported .glb files, imported by Godot automatically
  scenes/         .tscn scenes (player, enemies, combat, levels, ui)
  scripts/        GDScript, mirroring the scenes folders
  tests/          Headless smoke test
docs/             Design notes
```

## Blender to Godot pipeline

See [blender/README.md](blender/README.md). In short: model in Blender, export to `game/assets/models/*.glb`
with `blender/scripts/export_glb.py`, and Godot re-imports it on the next focus.

## Testing

A headless smoke test loads the level, drives the player with simulated input and checks movement,
melee, dodging, shooting, lock on, enemy attacks and enemy death:

```
godot --headless --path game --import
godot --headless --path game --script res://tests/smoke_test.gd
```

It runs on every push through GitHub Actions (`.github/workflows/smoke-test.yml`).

## Large files

`.blend` and `.glb` files are committed directly for now. When the art grows (textures, many models),
switch them to [Git LFS](https://git-lfs.com/) with `git lfs track "*.blend" "*.glb" "*.png"`.
